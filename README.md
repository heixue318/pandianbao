# 盘点宝 Android

单机库存盘点应用，包名为 `com.fengluanchui.pandianbao`，当前版本为 `1.0.0`。

## 已实现的首个里程碑

- Kotlin、Compose 与 Room 工程骨架
- 商品库：原始条码、名称和可选的同条码变体说明
- 多库位，每个库位维护独立库存余额
- 手动入库、出库和盘点。操作单数量必须为正数，库存余额允许为负数
- 盘点按实盘数量与当前库存计算差额，并写入不可变库存流水
- 首次启动自动建立“默认库位”
- 已使用确认的盘点宝品牌图标
- 离线相机扫码：内置识别模型，识别后自动进入商品或数量录入
- GitHub Release 检查更新和系统安装：下载后校验文件大小、SHA-256、Release 标签、包名、版本号和签名

## 数据规则

盘点不会直接覆写余额：每次保存创建一张盘点单和一条调整流水。后续编辑已完成盘点时，应作废原调整流水后重新计算并写入新流水，以保留审计轨迹。

Room schema 已导出到 `app/schemas/`。后续数据库版本升级必须提供显式迁移，禁止破坏性迁移。
